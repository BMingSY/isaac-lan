## 集中实机验收

两端使用带 `.isaac-lan-lab` 标记的 `host-001` 与 `client-001`，自动加载扩展，普通 Lua 沙箱，75 ms 单向附加延迟，250 ms 连续画面采样。两端加载同一份未修改的 Stats+、EID、GoodTrip。源楼层与战斗速度使用既有测试夹具，检查范围是指定联机机制，并非从第一层开始的完整无辅助通关。

`r1` 在主机初始化新增移动夹具时发现普通沙箱没有 `io`，尚未启动客机和玩法检查。主机正常退出（`00000000`），隔离存档逐文件恢复。修正夹具以使用注入的测试参数；文件导出成为可选诊断，碰撞和停止收敛断言仍执行。`r2` 为重新加载初始化夹具启动一对新进程，所有场景复用这一对进程，仅保存退出并重建会话。

`r2` 主机 PID 为 31448，客机 PID 为 2940，十项均复用这两个进程；包含启动、验收和收回的总耗时约 738 秒。两端退出码均为 `00000000`，profile、游戏 data 和联机会话目录全部恢复并通过逐文件哈希核对。

Home 睡醒移动记录位移 146.81、94 个行走 tick，教条入场后记录位移 130.96、96 个行走 tick；矿车抵达与返回分别有 80、100 个实际行走 tick。两端均触发原生胜利回调，GoodTrip 客机动作返回 `applied / arrived`。画面抽查覆盖移动碰撞、里拉撒路合房和 Home 教条客厅；250 ms 采样不等于对每个渲染帧的完整验收。
