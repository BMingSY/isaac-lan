# 道具与效果兼容清单

| 道具／效果 | 兼容后的效果 |
| --- | --- |
| 指南针（The Compass） | 任一队友持有时，全队共享特殊房间位置显示，分房后仍生效。 |
| 藏宝图（Treasure Map） | 任一队友持有时，全队共享楼层布局显示，分房后仍生效。 |
| 蓝地图（Blue Map） | 任一队友持有时，全队共享秘密房位置显示，分房后仍生效。 |
| 打折（Steam Sale） | 商店折扣计入全队持有数量，分房后仍生效。 |
| 黑蜡烛（Black Candle） | 任一队友持有时，为全队清除楼层诅咒，分房后仍生效。 |
| 补货（Restock） | 任一队友持有时，全队共享商店补货效果，分房后仍生效。 |
| 十字圣球（Sacred Orb） | 任一队友持有时，全队共享道具品质筛选效果，分房后仍生效。 |
| 错误技（TMTRAINER） | 任一队友持有时，各房间共享错误道具生成效果；拾取后的道具及随机效果仍归拾取者。 |
| 达摩剑（Damocles） | 额外道具底座对全队各房间生效；受伤判定和落剑风险仍由持有者承担。 |
| 创世纪（Genesis） | 使用者进入特殊房间并重选道具，队友背包保留；通过原生出口换层时全队进入下一层。 |
| 深口袋（Deep Pockets） | 任一队友持有时，提升全队金币上限，分房后仍生效。 |
| 死亡证明（Death Certificate） | 全队进入并在任一玩家拿取后返回来源房间；队友及双角色身体使用目标房间落点，内部可分开探索，传送卡限于该维度。 |
| 恶魔／天使房概率相关效果（五芒星、羊头、圣体、钥匙碎片、忏悔书、美德之书等） | 异房队友持有的加成和临时保证开门效果也计入全队概率，保留原版叠加与优先级。 |

公共被动效果由 [`team_effects.h`](https://github.com/BMingSY/isaac-lan/blob/main/src/compat/items/team_effects.h) 声明；后端只在原版查询期间借用完整队伍名单并及时恢复，保留原版叠加公式，库存和个人属性仍归持有者。恶魔房价格按实际买家重新计算，固定价与免费道具保持原值。
