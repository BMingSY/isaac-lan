# 道具与效果兼容清单

| 道具／效果 | 兼容后的效果 |
| --- | --- |
| 指南针（The Compass） | 任一队友持有时，全队共享特殊房间位置显示，分房后仍生效。 |
| 藏宝图（Treasure Map） | 任一队友持有时，全队共享楼层布局显示，分房后仍生效。 |
| 蓝地图（Blue Map） | 任一队友持有时，全队共享秘密房位置显示，分房后仍生效。 |
| 打折（Steam Sale） | 商店折扣计入全队持有数量，分房后仍生效。 |
| 黑蜡烛（Black Candle） | 任一队友持有时，为全队清除楼层诅咒，分房后仍生效。 |
| 补货（Restock） | 任一队友持有时，全队共享商店补货效果，分房后仍生效。 |
| 十字圣球（Sacred Orb） | 任一队友持有时，全队共享道具品质筛选效果，分房后仍生效。 |
| 深口袋（Deep Pockets） | 任一队友持有时，提升全队金币上限，分房后仍生效。 |
| 恶魔／天使房概率相关效果（五芒星、羊头、圣体、钥匙碎片、忏悔书、美德之书等） | 异房队友持有的加成和临时保证开门效果也计入全队概率，保留原版叠加与优先级。 |
