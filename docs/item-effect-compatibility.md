# 道具与效果兼容清单

| 道具／效果 | 兼容后的效果 |
| --- | --- |
| 指南针（The Compass） | 任一队友持有时，分房后仍共享特殊房间位置显示。 |
| 藏宝图（Treasure Map） | 任一队友持有时，分房后仍共享楼层布局显示。 |
| 蓝地图（Blue Map） | 任一队友持有时，分房后仍共享秘密房位置显示。 |
| 打折（Steam Sale） | 商店折扣计入全队持有数量，分房后仍生效。 |
| 黑蜡烛（Black Candle） | 任一队友持有时，为全队清除楼层诅咒。 |
| 补货（Restock） | 任一队友持有时，分房后仍共享商店补货效果。 |
| 十字圣球（Sacred Orb） | 分房后仍共享道具品质筛选效果。 |
| 深口袋（Deep Pockets） | 全队共享金币上限，分房后拾取和消费保持一致。 |
| 金币、炸弹、钥匙 | 同房、分房及幽灵状态下保持全队共享数量。 |
| 恶魔／天使房概率相关道具与饰品 | 五芒星、羊头、圣体、钥匙碎片、忏悔书、美德之书等效果计入全队概率，保留原版叠加与优先级；两端显示一致。 |
| 临时保证开门效果 | 在其他已加载房间生效时，也计入全队开门概率。 |
| 主动、饰品、卡牌与药丸槽位 | 保留正确槽位、充能与口袋切换顺序。 |
| 合成袋（Bag of Crafting） | 同步材料顺序和合成预览；失去道具后清除旧显示。 |
| 联机挑战 1001 的合成袋 | 显示固定下一位玩家的材料与预览，自己的卡牌和其他口袋物品正常显示；下一位缺席、为幽灵或无袋时隐藏材料与预览。 |
| 药丸颜色与鉴定 | 两端的颜色对应效果及鉴定状态一致，沙漏回退可恢复之前的状态。 |
| 药丸、卡牌使用 | 效果由主机结算，客机同步结果，避免重复生效。 |
| 楼层诅咒 | 全队共享同一份诅咒，换层、消咒和回退后的地图与状态一致。 |
| 迷宫诅咒（Curse of the Maze） | 客机到达主机选定的房间，避免再次随机跳房；诅咒继续保留。 |
| 白火临时游魂效果 | 两端同步临时变身及其解除。 |
| 死亡证明（Death Certificate） | 全队进入；任一玩家拿取道具后，全队返回来源房间。 |
| 死亡证明内的传送卡／传送效果 | 仍在死亡证明区域内传送，目标不存在时回到该区域入口。 |
| 发光沙漏（Glowing Hour Glass） | 按使用者的进房记录回退全队状态和位置；出生房、Home 及贪婪特殊落点遵循原版结果。 |
| R Key | 全队一起重开并进入同一新楼层。 |
| 遗忘我（Forget Me Now）、五点骰子房 | 全队一起重新生成当前层，保留原版的库存与资源结果。 |
| 普通道具／卡牌传送、传送门 | 只迁移对应玩家及随行角色，其他房间的队友继续游戏。 |
| 死猫、嗝屁猫的项圈、安卡、1up! | 原生复活转场后恢复角色显示，避免复活后身体一直隐藏。 |
| 跟班与附属刀具 | 随所属角色跨房，避免同步替换时丢失或错误归属。 |
| 道具、卡牌、药丸的拾取／使用提示 | 只显示给触发者，同房队友也不会收到重复提示。 |
| 书类道具、Mega Mush 演出 | 各玩家独立显示演出，避免阻断队友的道具输入；Mega Mush 演出结束后恢复角色显示。 |
| 长子权（里拉撒路） | 双身体正确显示、切换并跨房。 |
