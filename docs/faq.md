# 常见问题（FAQ）

安装步骤见[README](https://github.com/BMingSY/isaac-lan/blob/main/README.md)。

## 进度与成就

### Q：主机和客机进度不一致，能一起玩吗？

A：可以。局内路线、道具解锁等以房主进度为准；客机已有的解锁不会开放房主未解锁的内容。选角和挑战资格仍按每个人自己的存档检查。

### Q：联机能解锁成就吗？

A：各端可保留本局相对房主开局进度新增的游戏内解锁。房主开局前已有的成就不会补给客机；扩展也不会主动补发 Steam 成就。

### Q：会覆盖我的个人进度或单人存档吗？

A：会保留个人原有解锁，计数只合并本局变化。单人 Continue 与联机存档分开管理；无法备份已有单人存档时会拒绝联机开局。

### Q：能选自己没解锁、但房主已解锁的角色吗？

A：原版角色不可以，按自己的存档判断。伊甸和里伊甸新开局需要本机有令牌，续玩或重连已有角色不重复要求令牌。

### Q：联机挑战会解锁原版挑战奖励吗？

A：不会。参加条件和通关方式见[联机挑战](https://github.com/BMingSY/isaac-lan/blob/main/docs/lan-challenges.md)。

## 存档与重连

### Q：可以保存，下次接着玩吗？

A：普通联机由房主保存退出；续玩需要原房主、原存档栏、原人数、原加入顺序和匹配的扩展构建。临时挑战不支持整场续玩。

### Q：客机掉线后要全员重开吗？

A：不用。房主继续游戏，掉线角色保留主要状态。客机回大厅重连后恢复原角色，回到房主当前房间；需保留原来的 `player-id.txt`，且房主会话仍在运行。

### Q：能中途加新人或更换房主吗？

A：目前不支持；掉线的原玩家可以重连。

## 玩法与 Mod

### Q：能分开探索吗？

A：可以在同一楼层分房探索和战斗，换层时全队一起进入下一层。

### Q：谁能暂停、保存和退出？

A：任何在线玩家可请求全队暂停，由发起者恢复；发起者离队后由房主恢复。客机可单独离队，只有房主能保存并结束整场会话。

### Q：所有人的 Mod 必须一样吗？

A：新增道具、角色、房间等内容的 Mod 需要各端一致。已适配的 Stats+、EID、GoodTrip 界面可按个人需要安装，见[兼容清单](https://github.com/BMingSY/isaac-lan/blob/main/docs/mod-compatibility.md)。Mod 差异只提示，能开局不代表所有功能都兼容。

## 安装与连接

### Q：支持哪些平台和版本？几个人能玩？

A：支持 2–4 人，使用 Windows 版《忏悔＋》`v1.9.7.17.J460`。Linux／Steam Deck 需使用该版本和 Proton 11.0-2 及以上，可与 Windows 混合组队。

### Q：版本号一样，为什么还提示扩展不匹配？

A：不同构建的指纹可能不同。所有人安装同一份完整扩展，并重启游戏再连接。

### Q：局域网联机入口在哪里？

A：从 Steam 启动，选择存档栏后进入 **Online／在线联机 → 局域网联机**。没有入口时，核对游戏版本与安装器选择的游戏目录；Proton 还需配置 README 中的启动选项。

### Q：不在同一局域网能玩吗？

A：客机能访问房主的 IPv4 或域名即可，使用 TCP，默认端口 **29506**。跨网络需自行配置可达路径及端口映射或转发。

### Q：连接失败先检查什么？

A：检查房主是否已创建房间、地址和端口是否正确、双方游戏与扩展构建是否一致，以及防火墙和转发是否允许对应 TCP 端口。

### Q：Ping 不高，为什么还有延迟？

A：Ping 只表示往返时间。伤害、拾取和换房还要等待房主处理；房主性能、状态传输和房间初始化也会影响响应。

### Q：升级或卸载会删存档吗？

A：会保留配置、联机存档和历史日志；新构建不一定能续玩旧联机会话。

### Q：遇到异常怎么反馈？

A：提交 [Issue](https://github.com/BMingSY/isaac-lan/issues)，附上游戏和扩展版本、主客机、复现步骤、双方 Mod 列表及对应启动的完整日志归档。
