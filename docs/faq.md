# 常见问题（FAQ）

安装与联机步骤见[项目 README](https://github.com/BMingSY/isaac-lan/blob/main/README.md)。这里集中回答进度、成就、存档和联机中的常见问题。

## 进度与成就

### Q：主机和客机的解锁进度不一致，还能一起玩吗？

A：可以，不要求所有人的存档进度相同。局内使用房主的进度作为共同基线，路线入口、道具解锁等受该基线影响。例如房主已解锁支线入口、客机尚未解锁时，本局仍可按房主进度生成入口；反过来，客机的解锁不会自动开放房主尚未解锁的内容。

选角和联机挑战的参加资格仍检查每个人自己的存档，不能借用房主的解锁。退出后，各自保留原有进度，并合并本局新增的解锁与计数变化。

### Q：客机能选自己没解锁、但房主已经解锁的角色吗？

A：原版角色不可以，按客机自己的存档资格判断。伊甸和里伊甸新开局还需要本机有伊甸令牌；续玩或重连已有角色时，不会再次要求新开局用的令牌。Mod 角色沿用游戏原生菜单的收录规则。

### Q：联机会覆盖我的个人解锁和累计计数吗？

A：正常保存、退出时会保留各自原有的解锁，只把相对共同基线新增的解锁合并回去；累计计数按本局变化量合并。例如你原有某项计数 12、房主基线为 1000，本局增加 3，结束后你得到的是 15。

房主原有的整份进度不会直接写成客机的个人进度。相关机制曾修复过覆盖问题，见[存档回归记录](https://github.com/BMingSY/isaac-lan/blob/main/docs/history/issue-regressions.md)。

### Q：联机能解锁成就吗？主机和客机都能获得吗？

A：可以保留本局新产生的游戏内解锁。玩法由房主运行，进度同步给客机；保存、退出时，各端把相对共同基线新增的解锁合并到自己的存档。是否产生解锁仍取决于游戏原本的判定条件。

这里说明的是游戏存档里的解锁与计数；扩展不会主动补发 Steam 成就。

### Q：房主已经全解锁，能带没解锁的客机补齐成就吗？

A：不能靠共享房主进度补齐。若某项成就在房主的开局基线里已经解锁，即使本局再次满足条件，也不会被视为本局新增解锁补给客机。客机原本就有的解锁会保留。

因此，能一起走某条路线、拿到某件道具，不代表客机永久获得了对应解锁。

### Q：联机挑战通关会解锁对应的原版挑战奖励吗？

A：不会。联机挑战有独立规则，完成时不记录原版挑战解锁，也不能把联机挑战编号当作原版挑战编号。

当前挑战的参加条件和通关方式见[联机挑战](https://github.com/BMingSY/isaac-lan/blob/main/docs/lan-challenges.md)。参加资格检查每个人自己的存档，共享房主进度不能替代资格。

## 存档、续玩与重连

### Q：我原来的单人 Continue 会被联机覆盖吗？

A：联机会话与原有单人 Continue 分开管理，退出联机后恢复受保护的单人继续存档。如果无法备份已有单人存档，会拒绝联机开局。

### Q：联机可以保存，下次接着玩吗？

A：普通联机会话可以，由房主保存退出。三个存档栏分别保存各自的联机会话；下次需要原房主使用原存档栏，并按原人数、原加入顺序集合。

联机存档还会检查扩展构建，升级后不能假定旧会话一定可以继续。临时联机挑战没有整场续玩入口，退出时也不会覆盖或删除已有的普通联机存档。

### Q：客机断线后，必须全员重开吗？

A：不必。房主会继续游戏并保留掉线角色的道具和主要状态；离线角色暂时不参与战斗和奖励人数计算。客机返回局域网大厅，使用原玩家标识重连后，会恢复原角色并回到房主当前房间，无需等待下一层。

重连依赖原会话仍存在、扩展构建一致，以及原来的 `player-id.txt`，不要删除或更换该标识。恢复沿用原版保存／续玩机制，临时实体和部分计时可能重新生成或重置。详见[当前层重连](https://github.com/BMingSY/isaac-lan/blob/main/docs/session-lifecycle.md#当前层重连)。

### Q：游戏开始后，可以中途加入一个新玩家吗？

A：目前不支持。运行中的加入用于恢复原来的掉线玩家；新玩家需要在开局前进入大厅。

### Q：房主退出后，能把房主交给其他人继续吗？

A：目前不支持房主迁移。房主保存退出会结束整场会话；之后按原房主、原存档栏、原人数和原加入顺序续玩。

## 玩法与 Mod

### Q：大家必须待在同一个房间吗？可以各走各的楼层吗？

A：可以在同一楼层分房探索、战斗，并随时去队友房间汇合。换层由房主统一协调，全队进入下一层，不能分别推进不同楼层。

### Q：客机能暂停、退出或保存游戏吗？

A：在线玩家都可以请求全队暂停，由发起者恢复；发起者离队后由房主恢复。客机可以单独离队，只有房主可以保存并结束整场会话。打开暂停菜单后的光标、物品列表和设置由各端自己操作。

### Q：所有人必须安装完全相同的 Mod 吗？

A：新增道具、角色、实体、房间或资源的 Mod，各端需要一致的内容定义、资源和 ID 映射。扩展不会自动复制 Mod 文件、配置或私有数据。

已适配的 Stats+、EID 基础界面和 GoodTrip 地图界面可以按个人需要安装，房主不必安装同样的界面 Mod。具体版本与功能范围见[第三方 Mod 兼容清单](https://github.com/BMingSY/isaac-lan/blob/main/docs/mod-compatibility.md)。

### Q：Mod 不一致只提示，没有阻止开局，就说明兼容吗？

A：不能据此判断兼容。Mod 差异只做提示，不会自动识别所有内容冲突；相同的 Mod 列表也不代表任意玩法和私有数据都已适配。出现异常时，可先用双方一致的 Mod 配置缩小范围，再结合[兼容清单](https://github.com/BMingSY/isaac-lan/blob/main/docs/mod-compatibility.md)核对。

## 安装与连接排查

### Q：支持哪些版本和平台？几个人能玩？

A：支持 2–4 人，针对 Windows 版《以撒的结合：忏悔＋》`v1.9.7.17.J460`。Linux／Steam Deck 使用该 Windows 版本和 Proton 11.0-2 及以上，可与 Windows 混合组队；安装方法见[README](https://github.com/BMingSY/isaac-lan/blob/main/README.md#安装)。

### Q：双方显示的版本号相同，为什么仍提示联机扩展不匹配？

A：除了协议版本，还会核对扩展构建指纹。相同版本号下的不同构建也可能不匹配；所有玩家应安装同一份完整联机扩展，并重启游戏后再连接。

### Q：安装后，局域网联机入口在哪里？

A：从 Steam 正常启动游戏，先选择存档栏，再进入 **Online／在线联机 → 局域网联机**。如果没有入口，先核对游戏版本，以及安装器是否选择了本次启动的 `isaac-ng.exe`；Linux／Steam Deck 还需按 README 配置启动选项。

### Q：不在同一个局域网，也能连接吗？需要什么端口？

A：房主地址可以填写 IPv4 或能解析到 IPv4 的域名，使用 TCP，默认端口为 **29506**，可在界面修改。跨网络连接需要自行提供客机能访问房主的网络路径，并让防火墙、端口映射或转发配置允许该 TCP 端口。

### Q：一直连不上房主，先检查什么？

A：按顺序检查：

1. 房主已创建房间，客机填写的地址和端口与房主提供的一致。
2. 所有人使用相同游戏版本与同一份扩展构建，更新后都已重启游戏。
3. 房主防火墙允许对应 TCP 端口；跨网络时，映射或转发的目标与端口正确。
4. 若仍失败，保留两端同一次连接尝试的日志和错误提示，提交问题。

### Q：Ping 不高，为什么拾取、受伤或过门仍有延迟？

A：Ping 是往返时间，包含轮询和排队耗时，不等于完整玩法响应时间。客机移动有本机预测，伤害、拾取和换房仍等待房主结果；房主模拟、状态采集和房间初始化也会影响手感。

持续卡顿时，可按[README 的日志配置](https://github.com/BMingSY/isaac-lan/blob/main/README.md#配置与日志)开启性能统计并重启，保留两端同一局的日志。

### Q：升级或卸载，会删除联机存档和配置吗？

A：安装器升级和卸载会保留配置、联机存档及历史日志。升级使用新安装包重新安装，卸载按[README](https://github.com/BMingSY/isaac-lan/blob/main/README.md#卸载)操作。保留文件不代表新构建一定能加载旧联机会话。

### Q：遇到崩溃、掉线或同步异常，反馈时要带什么？

A：到 [Issues](https://github.com/BMingSY/isaac-lan/issues) 写明游戏和扩展版本、主客机、复现步骤及双方使用的其他 Mod，并附上两端对应启动的完整日志归档。说明异常发生在开局、换房、换层、重连还是退出时；若只在特定角色、道具或路线出现，也一起注明。
