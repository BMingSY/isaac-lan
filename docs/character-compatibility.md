# 角色兼容清单

| 角色／效果 | 兼容后的效果 |
| --- | --- |
| 里店长 | 全队共享特殊商店布局和定价，首层及分房后均生效。 |
| 店长、里店长的恶魔房交易 | 按实际购买者显示价格和结算：店长使用金币，其他角色使用血量。 |
| 里游魂（Tainted Lost） | 分房后仍影响全队道具筛选、低品质道具重抽和神圣卡生成，保留原版概率。 |
| 里拉撒路 | Flip 切换后，两端的身体、位置、库存和控制权保持一致。 |
| 里拉撒路＋长子权 | 双身体可正确显示、切换并一起跨房。 |
| 里雅各 | 暗以扫随所属角色跨房，重新进入房间后继续跟随。 |
| 雅各与以扫 | 两名角色保持同一玩家的控制与跨房归属，本机界面保留双角色布局。 |
| 遗骸与灵魂 | 形态切换、控制权和跨房后的角色状态保持一致。 |
| 里 ??? | 便便法力与法术队列顺序在两端保持一致。 |
| 里该隐／合成袋持有者 | 同步袋内材料及合成预览，分房后仍正确显示。 |
| 伯大尼、里伯大尼 | 灵魂充能、鲜血充能在两端保持一致。 |
| 白火临时游魂形态 | 两端同步变身及清房后的恢复。 |
| 合作幽灵 | 两端同步死亡与复活状态，异房队友击败 Boss 时也能参与原版复活。 |
| 伊甸、里伊甸 | 新开局保留令牌要求；续玩和重连已有角色时不重复要求令牌。 |
| 已加载的 Mod 角色 | 大厅可显示并选择原版角色菜单收录的 Mod 角色及其里角色。 |
