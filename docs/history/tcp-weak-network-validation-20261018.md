## 交付观测与未采纳方案

固定房间后的对照为 `tcp-weak-baseline-20261018-02`，最终候选为 `tcp-weak-candidate-20261018-06`。统计从 tick 60 开始，使用同机时钟；时间加权视图年龄包含等待下一份状态期间持续变旧的时间。

| 观测 | 对照 | 最终候选 |
| --- | ---: | ---: |
| 观测时长 | 50.020 s | 50.068 s |
| 应用状态数 | 1,358 | 1,362 |
| 应用间隔均值／P95 | 36.861／50 ms | 36.788／50 ms |
| 到达状态年龄均值／P95 | 101.581／181 ms | 113.051／224 ms |
| 时间加权视图年龄均值／P95 | 129.351／283.667 ms | 141.691／328.987 ms |

候选这轮年龄指标高于对照；单轮、非独占观测不能证明延迟改善或性能不退化。最终改动保留已有状态发送策略，收益范围限定为应用层输入队列的有界性和过时采样合并，不能声称已解决校园网的所有偶发卡顿。

曾尝试按迟到回执缩窗及限制最旧在途状态年龄。候选 01–03 的功能通过，但时间加权尾部延迟退化；只看到达时的状态年龄会得到误导性结论。修正重复缩窗、恢复节奏和调度余量后，候选 05 在固定房间中仍得到视图年龄均值 146.715 ms、P95 364.025 ms，高于同夹具对照，因此最终移除该策略及短期 RTT 基线更新。
