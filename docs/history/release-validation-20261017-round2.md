## 调度、画面与恢复

全部实机来自带归属标记的隔离目录和独立端口；启动前备份配置、存档及日志。普通路线与 Boss 分片并行，真实键盘／菜单检查独占焦点；开启属性栏和道具栏。未控制手动游玩实例。

基础战斗首次诊断、Boss 分片 0 和连续路线组在失败后无法正常关闭的所属进程由工具终止，保留退出码及堆监视结果。独立诊断用于区分夹具问题与长流程状态影响，不能用未重现替代根因修复。`mother-beast-diagnostic-01` 的参数拼写错误在启动游戏前退出，不计为实机失败。

已抽查双端基础玩法与 HUD、Horny Boys、Rotgut 胃室、Beast、客机 EID／水流／大房间，以及两个长流程失败时的画面。`visual-review.json` 仅列实际查看的样本，不代表逐帧人工审阅。

15 个执行／诊断组全部恢复资料，24 个受保护目录的最终文件哈希和存在状态与备份一致；所属游戏实例全部关闭。冻结原生程序、三份源码归档和安装包哈希未变化。检查结果见 `final-restoration.json`：恢复与产物校验通过，整体验收仍为失败。

高负载卡顿／编码开销、织布魔偶客机分房和错误技历史随机崩溃沿用[第一轮记录](https://github.com/BMingSY/isaac-lan/blob/main/docs/history/release-validation-20261017.md)及 PR #88 的限定结论；本轮未执行相关全量专项，不将其标为已解决。
