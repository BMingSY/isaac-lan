## 失败与未验证项

- `attack-probe-20261022-01` 保留原生基线；02 的机制探测虽通过，但预测弹接管不足。后续修正输入序号匹配和初始 D6 外观识别后另开回归，未把早期机制通过等同于完整攻击通过。
- `attack-response-20261022-01` 在武器切换边界断言失败：已应用快照先于前端状态轮询。修正夹具按实际武器类型判断，旧轮保留为失败；02 完成普通攻击专项。
- `attack-final-20261022-01` 在镜面夹具请求原生换层后继续执行 Lua 时出现访问异常。使用旧 DLL `f02781daf48c3b346043e59d9f2fc7c9b79ff5ac30317d3a59ca014a2aff84ef` 的 `attack-stage-baseline-20261022-02` 在相同 Lua 模块 RVA `0x2931f` 复现；两轮均保留主机转储。夹具改为请求换层后立即返回，后续两轮实际换层通过。原生异常底层原因未解决，不能据此宣称任意换层回调均安全。基线 01 因缺少实验启动器未能执行，不计通过。
- `attack-final-20261022-02` 的镜面、攻击及挂载场景通过，第四场景因关闭 Lua 调试后 `io` 不可用而加载失败。既有蓄力夹具改用 runner 注入参数，最终 03 在相同限制下完整通过。
- `attack-draw-20261022-01` 的探测定位到泪弹高度绕过世界投影缩放。修正并补离线用例后，最终 03 对照原生画面通过。
- 多发、随机／特殊弹道、未知外观及全部道具／角色组合未遍历。硫磺火光束、妈刀投掷、圣剑挥击等实际攻击仍等待主机；本轮不提前判定命中、伤害、音效或道具效果。预览支持范围见[道具兼容清单](https://github.com/BMingSY/isaac-lan/blob/main/docs/item-effect-compatibility.md#攻击显示)。

## 进程与恢复

每轮只操作有归属标记的隔离主客机，按构建重载、失败后恢复或画面诊断需要重新启动；兼容场景在同一组进程中依次执行。最终 03 用同一对进程完成镜面、六类攻击及权威蓄力检查，耗时约 170 秒。主机 PID 13100、客机 PID 32060 均以代码 0 正常退出，堆转储为 0，保护目录恢复后逐文件哈希一致。

所有已结束轮次的恢复报告均为 `restored=true`。旧失败报告、日志、画面及转储保留原始结果，后续通过没有覆盖旧证据。手动试玩另开 `manual-attack-ping80-20261022-01`，使用相同候选及每方向 40 ms 延迟；其进程由用户操作，资料恢复以该会话结束后的独立恢复报告为准。
