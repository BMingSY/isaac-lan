# LANBOT 初版验收

历史记录：保留初版接入的范围与未验证项，后续结果见[验收索引](README.md#lanbot)。

## 初版验证记录

新增无需游戏的 Lua 测试覆盖控制台回调、命令与生命周期、本机归属、模式与风格、岔路探索、出口等待、路径受阻、障碍绕行、动态危险和蓄力射击。原生输入测试覆盖人工／人机切换、界面输入保留、按下边沿、预测一致性与过期释放，并纳入现有 CTest／CI。

[离线行为场景](../development-and-testing.md#离线测试)持续运行真实人机代码，覆盖四向过门、速度／碰撞半径／起点组合、绕墙、留守与暂停恢复；三个门前／路径点停滞场景作为固定回归保留。模拟运动模型不能单独证明原生物理、真实战斗或实际通关通过。

隔离双实例使用 Repentance+ 1.9.7.17.J460、种子 `LBCD0G4M` 和双阿撒泻勒，已验证原生控制台命令、主机接管、`hold` 留房、客机独立过门，以及 `pause`／`resume`／`off` 的人工输入切换。修复了该版本忽略 `lanbot` 命令的问题。

探索实测发现门前停滞；轨迹评分与门边界修复当时只通过持续过门回归测试，后续补充的过门检查见[普通路线验收](lanbot-verification.md)。主客机托管的普通 Boss 房战斗、逐层推进和正常结局已通过该记录中的加速流程；这轮未验收无保护随机地图探索、全部 Boss 预兆／武器、四人、高延迟、特殊解谜及通用走位质量。四人指定配装的普通贪婪验收见[贪婪挑战](lanbot-greed-challenge.md)；其余场景仍需按范围验证。后续优先使用无需游戏的行为回归，实机验证按原生接入风险选择少量场景；[设计文档](../lanbot-design.md#性能与验证)保留了验证目标。
