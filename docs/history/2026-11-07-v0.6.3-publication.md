## 工坊上传与恢复

默认语言与简体中文两次提交均返回 `result=1`、`legal_agreement_required=false`。内容仅上传一次，包含原 Lua 入口、版本元数据、封面、安装说明及本次 ZIP／校验文件，旧 ZIP 未保留。

首次回读校验失败：简体中文介绍正确，但此前可见的标题 `Isaac LAN / 局域网联机` 返回为空。原始失败、两次成功回执及后续只读复查均保留，没有重传内容或重复提交更新记录。

[发布工具](https://github.com/BMingSY/isaac-lan/blob/main/tools/workshop_release.py)现于更新介绍时，同时传回快照中非空的该语言标题；快照为空则不写标题。[原生工具](https://github.com/BMingSY/isaac-lan/blob/main/tools/workshop.cpp)的 `update-page` 支持可选标题参数，旧参数形式仍有效。定向离线检查 39 项通过，新增用例能拒绝旧行为，Windows x86 工具构建、格式和语法检查通过。

确认远端只有上述标题差异后，以相同介绍、空更新说明且不带内容和封面，补交原有中文标题；成功回执及后续核对均通过。此操作不改变已经发布的游戏二进制，不新增发版或游戏验收轮次。

最终同时确认两种语言的标题、介绍、归属、可见性和封面地址符合预期；重新下载的全部六个文件逐文件哈希匹配准备清单，其中 ZIP 与 GitHub 正式包哈希一致。公开更新记录页最新一条与已确认文案一致，且只有一条本次记录；工坊详情页受到 HTTP 429 限流，其元数据通过 Steam API 核对。

证据标识为 `v0.6.3-20261107` 与 `workshop-v063-20261107-publish-01`。保留 GitHub 附件核验、二进制对照、上传／标题恢复回执、最终下载清单和网页核对结果；原始产物不提交到文档目录。
