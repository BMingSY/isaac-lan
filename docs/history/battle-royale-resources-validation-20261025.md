# 1003 资源房与混沌奖励专项（2026-10-25）

本专项检查资源房配额、出生点资源路径、第一圈供给、特殊房间入口与商品价格，以及 Boss 奖励跨道具池抽取。代码候选为 `011d779`，原生版本为 `1.9.7.17.J460`。入口为 [run_battle_royale.py](https://github.com/BMingSY/isaac-lan/blob/main/tools/run_battle_royale.py)，证据包为 `battle-royale-resources-20261025-01` 和 `battle-royale-resources-20261025-02`；原始日志、脚本、双端画面、报告和恢复哈希保留在测试产物。

## 检查范围与结果

- 9 项定向 CTest 通过：`bridge.state-layers`、`bridge.challenges`、`bridge.battle-royale`、`bridge.battle-royale-resources`、`bridge.battle-royale-rewards`、`bridge.battle-royale-hud`、`bridge.personal-map`、`bridge.layers`、`bridge.grids`。20 项分层／挑战配置 Python 检查、Windows x86 Release 构建、格式和脚本语法检查通过。
- 资源离线用例覆盖 16 个种子、已有资源计数、出生房／Boss 房／最终圈预留、出生点三步内的免费路径、首圈至少半数配额、模板失败重试及重复执行不增加房间。入口用例确认只解锁宝箱房和商店，未清场时不主动打开战斗封门。
- 奖励离线用例确认原本高品质的 Boss 底座也重新跨池抽取，至少一个品质不低于 3，额外底座可为低品质；已有混沌保留，抽取、变形或生成失败均清除临时副本。
- 第 02 轮实机初始地图有 16 个宝箱房、8 个商店、4 个书房和 4 个拱廊，第一圈内分别为 9、6、2、2；妈腿失败后的新地图总数相同，第一圈内分别为 8、4、3、3。两张地图均核对实际连接，出生点三步内可达宝箱房。
- 主机使用零钥匙实际走入宝箱房和商店；商店金币不足时无法购买，补足原价后正常扣费并取得商品。客机逐一进入四类资源房，确认原生房型同步；画面与日志核对宝箱房底座、商店价签和货物、书房书籍及拱廊机器。
- 使用生产奖励组件和原生道具池连续抽样 24 次，均达到品质保底且临时混沌清除，抽取来源包含道具池 `0、3、4、5、23、24`。抽样代理不消耗权重；随后实际普通 Boss 与妈腿结算使用未替换的生产抽取接口。
- 同一主客机连接继续验证正常 1UP、最后幸存者自动进入 Boss、临时教条完整效果、奖励阶段保留／假换层移除、原有教条保留、品质保底、清场不复活、胜者跳过奖励、妈腿失败续局及最终奖杯结束。双端控制台隐私和个人地图断言同时通过。
