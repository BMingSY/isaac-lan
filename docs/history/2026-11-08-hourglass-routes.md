## 复现与修复范围

`baseline-09` 经原生光柱到达教堂（stage 10、type 1），回退至子宫二后 `STATE_HEAVEN_PATH` 仍为 true；随后从原生地洞出发，又到达 stage 10、type 1，触发预期 type 0 的断言失败。
