Windows x86 构建、格式、脚本语法检查通过。网络用例 `ending-events`、`ending-liveness`、`handshake`、`run-rules`、`stage-events`、`progression`、`commands`、`cinematic-events`、`loading-exit`、`host-disconnect` 均通过；结束事件覆盖 2～4 人、普通／挑战会话、重复事件及紧接关闭的交付，保活用例在无玩法输入和快照的情况下持续 22 秒。测试目录发现与只读计划的 4 个 Python 用例通过。
