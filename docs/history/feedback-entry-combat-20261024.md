# 钥匙门、妈刀、Boss 血条与下降演出：2026-10-24

本记录对应用户在 PR #117 的双实例手动游玩中补充的四项问题，没有单独的 feedback 编号。基线为 `f0097a5a05dfcc2e3ab47d5d34c05011337c2d75`，种子 `LBCD0G4M`，Windows x86 `1.9.7.17.J460`，UDP 每方向 40 ms，无额外抖动、丢包或自动性能压力。修复候选为包含本记录的提交，冻结构建标识 `v051-four-issues-build-20261024-05`。

这是[候选全路线验收](https://github.com/BMingSY/isaac-lan/blob/main/docs/history/release-validation-20261024-v051.md)之后的定向补充，不把此前冻结 DLL 的 107 个 Boss、六条结局与其他路线结果记为新 DLL 的重跑结果。原始日志、逐帧画面、HUD 采样及存档保留在私有验收产物中。

## 原因与修复

| 用户反馈 | 实机原因 | 修复与边界 |
| --- | --- | --- |
| 进入需要钥匙的房间卡一下 | 客机移动预测先撞上仍锁着的墙，等待主机解锁后再前移；真实本机输入下停步约 80 ms | 本机资源足够的普通单锁／双锁门允许最多 250 ms 的门前预览，限制在源房间内；不解锁、不扣钥匙、不选择目的地。主机确认后接入原有过门流程，拒绝或超时恢复碰撞。预览按身体分别保存 |
| 妈刀飞行轨迹帧数低 | 返回式刀刃飞行时原生 `Velocity` 为零，旧逻辑只补父角色平移，刀刃自己的轨迹随快照跳动 | 在父实体坐标系内估算连续轨迹，再合成本机父实体显示位置；复用原有外推上限与纠偏，清理父实体替换／丢失、暂停和换房状态 |
| 第一层 Boss 半血突然死亡 | 同种子的 Blighted Ovum 主体 `IsBoss=true`、无敌伴生体 `false`；客机两者都为 `true`，把伴生体的满血加入分母与分子。基线主体约 8% 时客机血条仍约 52% | 通用 NPC 状态携带真实 `IsBoss()`，版本后端只恢复该布尔分类，原生 HUD 根据实际实体与血量计算，不同步一个独立血条比例 |
| 地下室／下一层没有进入动画 | 普通下降的起跳由主机入口网格逻辑启动，客机不执行这段玩法；楼层事件又会清理旧视图 | 已接受的普通下降事件启动本机角色原生 `Trapdoor` 动作；同层重置、上行、兼容组件接管的转场不套用此动作。小地下室入口接入本机过场淡出，取消和返回沿用现有生命周期 |

NPC 状态从 24 字节变为 25 字节，schema 33、协议 42。接口范围、布局、所有权和校验见[原生能力参考](https://github.com/BMingSY/isaac-lan/blob/main/docs/native-backend.md)，运动与转场职责见[房间与表现](https://github.com/BMingSY/isaac-lan/blob/main/docs/rooms-and-presentation.md)。

## 原始失败与必要重启

`v051-four-issues-20261024-01` 至 `12` 均保留，资料恢复检查全部通过。首次关闭用户交付的所属实例前，单独归档其两端画面、配置、存档及会话目录；只有启动夹具、加载新 DLL 或失败进程收尾需要重启。

| 轮次 | 原始结论 |
| --- | --- |
| 01 | 夹具缺少输入辅助对象，启动失败；主机被强制关闭，不能计为通过 |
| 02 | 输入编码调用错误导致没有真正行走，下降断言失败；该轮另外保留了血条错误的直接证据，两端被强制关闭 |
| 03 | 观察场景正常完成，重现刀刃轨迹与下降动画；只合成网络输入，不能证明本机钥匙门预测 |
| 04 | 基线增加分类诊断和测试用起跳原型，观察正常完成；证明主客机分类差异及原生动画调用的作用，不算生产修复验收 |
| 05 | 冻结构建缺少实验启动器，未启动游戏；补齐构建产物后另起一轮 |
| 06 | 首三项修复观察通过、双端正常退出；仍使用合成网络输入，未据此宣称钥匙门修复 |
| 07 | 虚拟手柄接口调用错误，主动中止并正常收尾 |
| 08 | 改为真实本机虚拟手柄输入，前三项通过并重现钥匙门停步；双端正常退出 |
| 09 | 已访问宝物门被测试强行重新设锁，原生门状态不等价于未解锁门，无钥匙反例无效且断言失败；改用未访问商店的原生锁。两端被强制关闭，不计整轮通过 |
| 10 | 反例的 `assert` 将第二返回值带入手柄 API，客户端参数错误；修正夹具并保留失败，客户端被强制关闭 |
| 11 | 四项新反馈与七类武器双端断言完成，但原有过门回归测得首次房间到达前 80 ms 位移 1.6232，超过原断言的 1。房间加载消耗了尚未绘制的淡入计时；改为第一次绘制开始计时，并补 500 ms 加载延迟离线回归，没有放宽原位移断言。客户端被强制关闭，整轮仍记失败 |

失败退出产生的堆观察器非零结果不计正常退出通过；这些轮次未产生堆转储。离线首轮的两个楼层回调 mock 缺项、一次格式检查失败也保留，修正后另轮通过，没有删除原报告或放宽生产断言。
