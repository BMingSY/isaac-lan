## 工坊发布

从 GitHub 正式包提取主体和更新清单，复用已确认文案，只更新现有条目的内容及更新记录。Steam 返回 `result=1`、`legal_agreement_required=false`；重新下载的全部文件与准备清单逐文件匹配，其中 ZIP 与 GitHub 正式包哈希一致。标题、各语言介绍、封面、可见性等元数据保持原样。

公开更新记录页访问返回 HTTP 429，未计为网页核对通过；上传回执、Steam API 元数据和实际下载核对均通过，没有因网页限流重复上传。
