| 轮次 | 结果与后续处理 |
| --- | --- |
| `restart-vote01` | 夹具选择未解锁角色，未进入测试；更正为可用角色 |

| `restart-vote09` | 结算与手柄四次重开通过，键盘未触发投票；改为显式读取物理键盘和手柄设备，保留该轮失败 |
| `restart-vote10` | 六次重开均完成；完成后夹具继续断言“两人在线”，正常关闭主机时误报并使客机被强制结束。该轮整体不计通过；夹具完成后停止会话断言 |

## 离线检查与限制

Windows x86 构建、格式检查、PowerShell 格式、Python／Lua 语法通过。相关投票、生命周期、聊天显示、菜单与分层用例通过；网络覆盖新局屏障、2～4 人连续重开、过期状态、离队空槽、归队等待、结算保活、换层与 R Key 道具。原生输入／菜单和存档相关回归通过。Python 工具、测试发现与分层检查共 68 项及 19 个子用例通过。

投票离线用例覆盖重复同意、20 秒超时、在线名单变化、旧运行／旧代次消息、加载阶段重试和原生退出尾部。四人重开和名单变化仅离线验证；最终实机范围为双人普通会话，未扩展到挑战、全角色、全道具或完整发版验收。狂暴死亡专项的范围与结果见[死亡结算验收](https://github.com/BMingSY/isaac-lan/blob/main/docs/history/game-over-validation-20261018.md)，其原版重开限制属于当时的候选结果。
