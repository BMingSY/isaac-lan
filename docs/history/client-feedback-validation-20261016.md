# 客机反馈与托管寻路修复验证（2026-10-16）

## 修改边界

- EID：实机确认客机可见道具距角色 60 单位、说明资格有效，但原生半径查询漏项。适配器仅在客机 EID 渲染作用域内，使用当前房间已提交的副本补足其固定查询，按距离过滤并去重；正常返回与报错均恢复原查询。零帧副本另使用 EID 的首帧说明约定。保留源码指纹、原版实体规则和卸载恢复，不修改上游源码或实体数据。
- 暂停：按客机实际菜单状态与主机状态对齐，清理失焦产生的本机菜单；重复暂停快照保留当前子页，退出选项页仍调用原生保存。
- 手柄：原先共享的 XInput 函数指针会被后加载的 DLL 覆盖，扩展状态查询在联机时也会误用普通入口。现按模块保存原入口，普通／扩展查询保持各自 `WINAPI` ABI；未连接设备仅在联机时提供空输入。没有新增游戏内存布局、Hook 或原生对象所有权。
- 托管：窄门处不再将撞门沿后的轴向滑动算作可用路径；仍只生成正常输入。
