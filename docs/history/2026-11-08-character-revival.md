## 最终验证

离线检查通过：78 项 pytest（分层和实机工具契约）、7 项 Linux CTest（角色形态、副本恢复及名单／房间作用域）、5 项 Windows 核心名单／房间测试，以及 `native.entity_links`、`native.forgotten-form` 两项 Windows 原生 ABI 测试。代码格式检查和 Lua 夹具／组合脚本语法检查通过。

最终轮 `regression-07` 使用有归属标记的 `test-harness-host-20261017`／`test-harness-client-20261017`，端口 `35030/35031`，每方向 40 ms 延迟，开启堆监测和双端 100 ms 录帧。通过隔离注入入口启动，不计自动加载验收。主客机各启动一次，十组场景在同一对进程内切换会话，逐场清理夹具。
