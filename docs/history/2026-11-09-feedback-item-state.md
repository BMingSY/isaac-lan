## 缺陷定位与失败记录

`native05` 在初始候选 `d459508` 上复现狂暴血狗返回重新加载的房间后丢失。仅将 NPC 纳入跟随集合不足以保留原生持久列表归属；修复后 `native06` 两种形态的跨房检查通过。该轮直接执行控制台换层绕过了正常楼层屏障，仍保留为失败；最终改用正常 `StartStageTransition`，由 `native18` 完成换层复验。

其余未通过轮次保留原始结果：`native01` 拒绝覆盖已有且不属于本轮的 Mod 目录；`native02` 至 `native04` 调整换房到达后的定位、EID 起局警告／观察窗口及房间局部实体 ID 的判定；`native07` 至 `native12` 修正零参数观察钩子、变身前提、弱苍蝇转为跟班、主动使用和底座接触等夹具问题；`native16` 移除 Lua 未提供的拾取物内部字段读取，改以实际库存切换确认结果。

`native13` 至 `native15`、`native17`、`native18` 将敌方 NPC 对友方苍蝇的真实伤害误认为玩家射击误闪。后续记录伤害来源并与权威事件对应，没有屏蔽合法受击。`native19` 的事件观察先结束、渲染观察仍继续，导致窗口外真实伤害被误报；两种观察统一时间范围后由 `native20` 复验。上述轮次均未改写为通过。

失败会话的回调已终止，无法继续执行夹具；修改构建或夹具后才另开轮次。`native02` 至 `native06`、`native08` 至 `native14`、`native16`、`native19` 清理时需要强制结束所属进程，不能计为正常退出。所有轮次隔离资料均恢复并通过哈希核对，没有控制其他游戏实例。
