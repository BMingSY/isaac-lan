## 修复验证

修复从主机描述符解析唯一的邻接入口，复用原有落点事务。传送、跨维度、地图外目的地及无法唯一解析的请求不推断入口；原有原生入口提示的处理保持不变。

- 8 项定向 CTest 通过，覆盖房间地图、作用域、转场上下文、落点、端点、连接设置及分层；原有 7 项运动、时间线、命中与射击 Lua 回归通过。
- Windows x86 构建与格式检查通过。
- `fixed-01` 同一对进程完成 `client-room-entry` 和原有 `room-entry`。前者两端分别核对 `StartRoomTransition`／`ChangeRoom` 在前两层的四次返回；后者核对宽商店入口，均通过。
- `fixed-02` 保持同一 DLL，使用关闭伤害闪烁的夹具补查入口画面。两端正常退出，隔离配置与存档逐文件哈希恢复。

基线首轮因 Cain 未解锁而未进入对局，不计为通过；后续加入解锁夹具。另起诊断轮用于增加主机轨迹与客机 API 采集，修复后重启用于加载候选 DLL。`fixed-01` 的坐标断言通过，但夹具反复补充无敌时间令角色闪烁，因此 `fixed-02` 调整夹具后补查可见落点。

玩家原始反馈、录像、日志及录帧仅保存在本地测试产物中。未清理服务器反馈，未修改用户手动游戏实例或上游 Mod。
