## 失败、重启与保留项

round1 因隔离目录中复制来的未归属加载器被安装保护拒绝，未启动游戏；保留该文件后重新准备隔离目录。round2～3 的命令与输入脚本通过，但当时自绘表情界面未满足需求，不计为最终界面通过。round4～5 验证原版轮盘并测量气泡素材，发现文字对齐问题。round6 清理诊断代码时漏掉夹具发言步骤，触发断言；主机随后无法正常退出，由所属 runner 强制关闭，堆观察器退出 5、无转储，此轮不计通过。round7 补回步骤后脚本通过，画面仍发现相邻文字气泡重叠。round8 增加离线避让用例并复测上述场景通过。

各轮重启用于加载修改后的 DLL／夹具；同轮主客机复用进程和连接。所有八轮备份恢复均逐文件核对一致，最终所属实例已关闭，未操作用户手动游玩实例。

尚未实机核对 Windows IME 候选窗口、聊天跨房／跨层／重连、四人界面和自定义外观组合；相应数据规则与配置解析由离线测试覆盖。初版文字编辑仍需要键盘，没有手柄软键盘或自定义表情导入。范围外已知玩法问题沿用既有记录。
