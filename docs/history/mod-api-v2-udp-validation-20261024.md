## 前置失败与修正

- `api2-udp-validation-20261024-01` 在创建游戏进程前拒绝覆盖兼容夹具目录。新隔离目录从旧隔离副本准备时继承了仅含 `disable.it` 的空占位；仅清理这些本次创建的空占位后继续。
- `api2-udp-validation-20261024-02` 安装适配成功，但旧 Mod 测试夹具仍提交 34 字节输入，游戏要求包含鼠标字段的 43 字节输入，因此得到 `Invalid local controls`。夹具改为共享输入编码，并补充离线解码检查；本轮没有计为场景通过。
- 第二轮进程正常退出并恢复资料后，第三轮启动包含单机回退边界修正的最终 DLL；没有通过反复重启跳过失败场景。
