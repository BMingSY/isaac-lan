# 2026-10-22 客机普通泪弹轨迹定向回归

本轮修正普通单发泪弹预览的弹速、移动惯性、出生位置、射程对应的下落过程及小数冷却。最终隔离双端检查通过，103 发预览全部被权威泪弹接管，无超时消失。这是开发专项，不代替发布验收或全道具／角色组合验证；此前攻击响应结果见[攻击回归记录](https://github.com/BMingSY/isaac-lan/blob/main/docs/history/attack-response-validation-20261022.md)。

## 早期失败与限制

- 用户上一轮手动会话 `manual-attack-ping80-20261022-01` 的最终计数为 153 次预览、106 次接管、46 次过期、1 次取消。旧过期计数混合碰墙与超时，不能把 46 次全部归为超时。
- `tear-trajectory-baseline-20261022-01` 缺少启动标记而未进入用例，不计通过。02 的长时间竖向移动可能触发换房，且直接设置射程未更新原生下落缓存，仅保留诊断证据。03 改用实际道具和较短往返，确认移动、弹速及射程变化后的接管缺失，并采集原生弹道。
- `tear-trajectory-fixed-20261022-01` 的诊断脚本运行完成，但短射程、长射程及点射仍出现 9、11、5 次超时，行为检查不通过。进一步确认原生冷却保留小数余量，修正后另开最终检查。
- `tear-trajectory-final-20261022-01` 在高弹速组失败：11 次预览、9 次接管、2 次碰墙、0 次超时。画面显示角色往返移动至上墙附近。专门验证接管的夹具改为向下射击、沿房间较宽的横轴往返，使接管期间远离墙面；未放宽断言，02 完整通过。靠墙正常终止的离线用例保留。
- 初始下落随机扰动采用均值近似，预览不消耗游戏随机数；主机实体保留实际随机结果。预览仍未经过原生完整房间着色与水面反射。
- 全部角色、多发、随机／特殊弹道及所有道具组合未遍历；特殊攻击支持边界见[攻击显示清单](https://github.com/BMingSY/isaac-lan/blob/main/docs/item-effect-compatibility.md#攻击显示)。本轮不提前判定伤害、命中或道具效果，也不扩大此前专项的验证结论。

## 进程与恢复

只操作有归属标记的隔离目录，每轮运行前备份配置、存档与日志。重启用于加载新 DLL、失败后恢复或重新采集诊断；最终轮次复用主客机完成全部八组检查，耗时约 145 秒。主机 PID 16272、客机 PID 23404 均以代码 0 退出，堆转储为 0，保护目录恢复后逐文件哈希一致。

所有已结束轮次均保留独立原始报告、画面及日志，恢复结果为 `restored=true`。本轮手动试玩使用 `manual-tear-ping80-20261022-01`，沿用相同 DLL 和每方向 40 ms 延迟；手动会话的恢复以用户关闭两个实例后的独立报告为准。
