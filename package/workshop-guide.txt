《以撒的结合》2–4 人局域网联机扩展。支持忏悔 1.7.9b.J835 和忏悔＋ 1.9.7.19.J511。可以分房探索与战斗、与队友汇合、断线重连，也可以加载其他 Mod。

安装
订阅后，在 Steam 库的 steamapps/workshop/content/250900/3817760679 目录找到安装包。关闭游戏，解压 ZIP。
Windows 用户运行 Install.cmd，选择游戏目录中的 isaac-ng.exe。
Linux 和 Steam Deck 用户选择 Proton 11.0-2 或更高版本，在解压目录运行以下命令，将引号中的路径换成游戏目录。
python3 install.py --game-directory "/path/to/The Binding of Isaac Rebirth"
在 Steam 游戏属性中填写启动选项。
WINEDLLOVERRIDES="winmm=n,b" %command%

联机
从 Steam 启动游戏并选择存档。忏悔在主菜单选择第三项「联机模式」即进入局域网联机。忏悔＋选择「联机模式」后，再选「局域网联机」。
一起联机的玩家需使用相同的游戏版本和扩展版本。切换忏悔和忏悔＋无需重装。

配置与反馈
配置文件在游戏目录下的 isaac-lan/config.ini，联机日志在原版 log.txt 同级的 isaac-lan/logs/。
遇到问题时，在联机聊天中输入 /feedback 问题描述，也可到 GitHub 的 BMingSY/isaac-lan 项目提交 Issue。
