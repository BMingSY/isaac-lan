02 / 约好队友，就出发

三步，开始这一局。

完整安装与联机指南 ↗
开局前确认

《以撒的结合：忏悔＋》Windows 版 v1.9.7.17.J460；所有玩家使用相同游戏版本和同一份联机扩展。

  1. 01

    下载并安装

    下载并解压完整安装包。关闭游戏，运行 Install.cmd，选择游戏目录里的 isaac-ng.exe。

  2. 02

    进入局域网联机

    从 Steam 正常启动游戏，选择存档栏，进入 Online / 在线联机 → 局域网联机。

  3. 03

    创建房间，叫上队友

    房主创建房间，分享 IP 或域名与端口。队友加入后选择角色并准备，由房主开始游戏。

Linux / Steam Deck 使用 Windows 版 J460 与 Proton 11.0-2 及以上，按指南运行 install.py 并配置启动选项。查看步骤 ↗

连接方式 默认端口为 UDP 29506，可在界面修改。跨网络游玩需要配置端口映射或转发。

03 / 出发前的小问题

你可能还想知道。

查看全部常见问题 ↗
会影响自己的单人存档吗？

单人 Continue 与联机存档分开管理。保留原有解锁，计数只合并本局变化。

能保存下来，下次继续吗？

可以，需要原房主、原存档栏、原人数、原加入顺序和匹配的扩展构建。临时挑战不能续玩。

中途可以加入新玩家吗？

暂不支持中途加入新人或更换房主。断线的原玩家可在房主会话仍在时，保留原来的 player-id.txt 重连。

连接不上，或者遇到问题怎么办？

先确认全员安装了同一份扩展并重启游戏，再核对房主地址、端口与防火墙。联机时可以在聊天中输入 /feedback 问题描述 提交反馈；收集范围见反馈说明。也可以到 GitHub Issues 报告问题。
